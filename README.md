# Colorimetric-algorithm-template
This template was developed to compare the colorimetry of red abalone gonads for the article: A minimally invasive approach to sex identification in red abalone (Haliotis rufescens) based on gonad color and neurohormone gene expression

This colorimetric alcorithm template was developed to compare the colorimetry of red abalone gonads in order to predict their sex through image analysis, based on their RGB values and by comparing them (using Euclidean distance) with a reference library of specimens whose sex is known.
